# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected security vulnerability.

Instead, contact the repository maintainer privately with:

- A description of the issue.
- Reproduction steps.
- Potential impact.
- Suggested remediation, if available.

## Sensitive data

Never commit:

- `.env` files or database connection strings.
- API tokens, passwords, or private keys.
- Raw user-submitted message content.
- Production database exports.
- Unreleased model artifacts containing restricted data.
